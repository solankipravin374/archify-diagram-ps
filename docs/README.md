# docs/

Drop the README hero image here as **`hero.png`**.

**What to use:** a screenshot or short GIF of a diagram rendered by `archify-diagram-ps` —
ideally with one node's detail panel open so viewers can see the captured ports / specs / IPs.

**Recommended size:** 1280×640 (2:1). PNG for a still, or `hero.gif` (then update the `<img>` src in the root README).

Until you add it, the README shows a broken image icon — that's expected.
